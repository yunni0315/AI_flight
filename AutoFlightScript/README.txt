# ✈️ 고정익 자율 정찰 및 표적 추적 시스템 사용 설명서

이 프로젝트는 라즈베리 파이, 카메라, 마텍(Matek) FC를 활용하여 고정익 항공기가 표적(TANK_PANEL)을 감지하고, 화면 중앙에 오도록 자동으로 방향을 제어하는 자율주행 소프트웨어입니다.

개발 지식이 없어도 main.py 파일 상단의 설정 수치(파라미터)만 변경하면 카메라 환경이나 기체 동작을 손쉽게 튜닝할 수 있습니다.

--------------------------------------------------
1. 주요 특징
--------------------------------------------------
- 실시간 표적 감지 YOLO (NCNN 경량화 모델)를 사용해 빠른 속도로 표적 추적
- 실시간 삼각측량 FC(비행제어기)의 고도 데이터를 실시간으로 받아 표적과의 거리 및 편각 계산
- 자동 방향 정렬 표적이 카메라 중앙에서 벗어나면 화면 오차를 계산하여 비행기를 해당 방향으로 기울임(Roll 제어)

--------------------------------------------------
2. 환경 세팅 및 실행 방법
--------------------------------------------------
[1] 필수 라이브러리 설치
터미널 창을 열고 아래 명령어를 입력해 필요한 라이브러리를 설치합니다.
pip install opencv-python ultralytics pymavlink

[2] 코드 실행
- SITL (시뮬레이터) 환경 테스트 시
  python main.py

- 실제 라즈베리 파이 + FC 연결 시
  main.py 파일 안의 connection_string을 시리얼 포트 경로로 수정 후 실행합니다.

--------------------------------------------------
3. 수치 변경 가이드 (비전공자용)
--------------------------------------------------
코드 수정 없이 main.py 파일 상단내부의 수치만 조정하세요.

[1] 카메라 및 표적 크기 설정
- KNOWN_WIDTH (기본값 300.0)
   탐지할 표적의 실제 가로 길이 (cm 단위)

- FOCAL_LENGTH (기본값 600.0)
   카메라 렌즈의 초점 거리 (px 단위)
   측정 거리가 실제와 맞지 않으면 이 값을 조정하세요.

- CONFIDENCE_THRESHOLD (기본값 0.5)
   표적 감지 최소 신뢰도 (0.0 ~ 1.0)
   잘 못 찾으면 0.3 ~ 0.4로 낮추고, 엉뚱한 물체를 인식하면 0.6 ~ 0.7로 높입니다.

[2] 비행 제어 및 민감도 설정
- KP_ROLL (기본값 0.05)
   조종 민감도 (P 게인)
   화면 중앙으로 너무 천천히 돌아오면 0.08 ~ 0.1로 높이고, 좌우로 심하게 흔들리면 0.02 ~ 0.03으로 낮춥니다.

- MAX_ROLL_ANGLE (기본값 20.0)
   비행기가 기울어질 수 있는 최대 각도 (도, ° 단위)
   안전을 위해 15.0 ~ 25.0 사이 유지를 권장합니다.

- ALIGN_TOLERANCE (기본값 20)
   중앙 정렬 인정 오차 (픽셀 단위)
   화면 중앙 기준 ±20px 내로 들어오면 정렬 완료로 판단합니다.

--------------------------------------------------
4. 터미널 출력 데이터 보는 법
--------------------------------------------------
프로그램 실행 시 출력되는 로그 예시
[타겟 추적] 오차 45px  편각 4.3°  수평거리 12.5m  고도 20.0m  지시 Roll 2.3°

- 오차 표적 중앙이 화면 중심에서 떨어진 거리 (양수 우측, 음수 좌측)
- 편각 카메라 중심 기준 표적이 위치한 각도
- 수평거리 고도를 반영하여 계산한 지상 표적과의 실제 거리
- 지시 Roll 표적을 중앙에 맞추기 위해 비행기에 전달한 기울기 명령값
- 🎯 [정렬 완료] 표적이 허용 오차 내로 들어왔을 때 출력됨

--------------------------------------------------
5. 자주 묻는 질문 (Troubleshooting)
--------------------------------------------------
Q1. 카메라를 열 수 없습니다. 에러 발생
- 카메라 케이블 연결을 확인하고 cv2.VideoCapture(0)의 0을 1이나 2로 변경해 보세요.

Q2. FC 연결 성공! 메시지가 뜨지 않고 멈춤
- SITL 시뮬레이터가 정상 작동 중인지 확인하거나, 실제 기체 연결 시 TXRX 선 및 보드레이트 설정을 확인하세요.
